Hidden controls

Long-press the mode button (or the blank area at the top): this panel. Closing it re-arms.
Long-press 1–9: step 1 fires on that = press. Re-arms.
Long-press 0: disarm. Again: re-arm the full queue.
Long-press %: step 1 becomes the date/time force above. Re-arms.
Long-press ×: encoding mode. The first number entered is hidden in the last digits of the result on the set = press. Long-press 0 twice to return to the queue.
Long-press AC/C: number on screen becomes step 1. Re-arms.
Long-press =: number on screen is added as a new last step.
Long-press decimal point: wipe. All forces cleared, disarmed.
Each hidden action clears the screen to 0.
